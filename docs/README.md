# 💰 Sistema de Gerenciamento de Receitas

### 📌 Sobre o projeto

O **Sistema de Gerenciamento de Receitas** é um projeto acadêmico desenvolvido para ajudar na organização e no controle financeiro de empresas. A proposta é reunir informações sobre receitas, despesas e resultados em um único sistema, facilitando o acompanhamento das movimentações financeiras.

Com as informações organizadas, o sistema busca tornar as consultas mais práticas, reduzir erros de controle manual e auxiliar na tomada de decisões.

### 🎯 Objetivo

Desenvolver uma solução simples e organizada para apoiar o gerenciamento financeiro, permitindo acompanhar as movimentações e consultar informações importantes sobre a situação financeira da empresa.

### ⚙️ Principais funcionalidades

- **Gerenciamento de receitas e despesas:** organização das entradas e saídas financeiras.
- **Controle das movimentações:** consulta das informações financeiras registradas.
- **Consulta de saldo e resultados:** acompanhamento do resultado financeiro.
- **Relatórios financeiros:** visualização de informações que ajudam a compreender o desempenho em determinado período.
- **Organização por categorias:** classificação das movimentações para facilitar a consulta.
- **Auditoria de ações:** registro de ações importantes para ajudar no acompanhamento e na rastreabilidade do sistema.

### 🎨 Design System

O projeto utiliza uma identidade visual baseada em quatro cores, cada uma com uma função na interface:

| Cor | Função | Exemplos de uso |
|---|---|---|
| **Azul — primária** | Identificar os elementos principais do sistema. | Menus, navegação, cabeçalhos e botões principais. |
| **Verde — secundária** | Representar ações positivas e informações favoráveis. | Receitas, confirmações e resultados positivos. |
| **Vermelha — terciária** | Destacar alertas e ações que exigem atenção. | Despesas, erros, avisos e exclusões. |
| **Quarta cor — detalhes** | Apoiar a organização visual sem chamar muita atenção. | Bordas, divisórias e informações secundárias. |

As cores devem ser utilizadas de forma consistente em todas as telas, mantendo uma interface organizada, legível e fácil de utilizar. Os tons exatos podem ser definidos de acordo com o protótipo visual do projeto.
